# GLOSSÁRIO

---

## Glossário

| Termo | Definição |
|---|---|
| **API** | Conjunto de regras e protocolos que permite a comunicação entre aplicações de *software*. |
| **Backend** | Parte do sistema que opera no servidor, responsável pela lógica de negócio, acesso à base de dados e processamento de pedidos. |
| **Blade** | Motor de *templates* do Laravel que permite a criação de *views* dinâmicas com sintaxe simplificada. |
| **CRUD** | Acrónimo para as quatro operações básicas sobre dados: Criar, Ler, Actualizar e Eliminar. |
| **Dashboard** | Painel de controlo visual que apresenta indicadores-chave de desempenho (KPIs) de forma resumida. |
| **Deploy** | Processo de disponibilizar uma aplicação num servidor para acesso pelos utilizadores finais. |
| **Eloquent ORM** | Componente do Laravel que permite mapear tabelas da base de dados para objectos PHP, simplificando o acesso a dados. |
| **Endpoint** | URL específica de uma API que responde a pedidos HTTP, representando um recurso ou operação. |
| **Factory Pattern** | Padrão de projecto que delega a criação de objectos a uma classe especializada, promovendo a extensibilidade. |
| **Framework** | Estrutura de *software* reutilizável que fornece uma base para o desenvolvimento de aplicações. |
| **Frontend** | Parte do sistema com a qual o utilizador interage directamente (interface gráfica). |
| **Hash (Bcrypt)** | Função criptográfica irreversível utilizada para armazenar palavras-passe de forma segura. |
| **Hot Reload** | Funcionalidade do Flutter que permite ver alterações no código em tempo real, sem reiniciar a aplicação. |
| **JSON** | Formato de dados baseado em texto, utilizado para a troca de informações entre aplicações. |
| **KPI** | Indicador quantitativo que mede o desempenho de uma actividade ou processo. |
| **Last-mile delivery** | Último trecho da entrega, desde o ponto de distribuição até ao destinatário final. |
| **Middleware** | Camada de *software* que intercepta pedidos HTTP para aplicar funcionalidades transversais (autenticação, logging, etc.). |
| **Migração** | Ficheiro que define alterações na estrutura da base de dados de forma programática e versionada. |
| **MVC** | Padrão arquitectural que separa a aplicação em três componentes: Modelo, Visão e Controlador. |
| **Polling** | Técnica em que o cliente verifica periodicamente o servidor para obter actualizações. |
| **Rate Limiting** | Mecanismo que limita o número de pedidos que um utilizador pode fazer num período de tempo. |
| **REST** | Estilo arquitectural para sistemas distribuídos que utiliza os métodos HTTP para operações sobre recursos. |
| **Role (Papel)** | Função atribuída a um utilizador que determina as suas permissões e acessos no sistema. |
| **Sanctum** | Pacote do Laravel para autenticação de APIs baseada em tokens pessoais de acesso. |
| **Sprint** | Período curto de desenvolvimento (1–4 semanas) no qual se implementa um conjunto definido de funcionalidades. |
| **Stock** | Quantidade disponível de um medicamento no inventário de uma farmácia ou filial. |
| **Token** | Sequência de caracteres gerada pelo servidor que representa a sessão autenticada de um utilizador na API. |
| **Trial** | Período gratuito concedido a uma farmácia após o registo, antes da cobrança de mensalidades. |
| **Webhook** | Mecanismo de comunicação em que um sistema externo envia automaticamente notificações ao servidor quando ocorrem eventos relevantes. |
| **Widget** | Componente visual reutilizável no Flutter que representa um elemento da interface do utilizador. |

## Definição de Termos e Variáveis do Sistema

**Tabela 6 — Níveis de acesso e permissões do sistema**

|---|---|---|

### A.1 — Motor de Busca de Medicamentos (BuscaMedicamentosController)

```php
public function __invoke(Request $request)
{
    $query = MedicineInventory::query()
        ->with(['medicine', 'owner']);

    if ($request->filled('q')) {
        $term = trim((string) $request->input('q'));
        $query->whereHas('medicine', function ($m) use ($term) {
            $m->where(function ($sub) use ($term) {
                $sub->where('name', 'like', "%{$term}%")
                    ->orWhere('barcode', 'like', "%{$term}%")
                    ->orWhere('category', 'like', "%{$term}%");
            });
        });
    }

    // Filtro por província (farmácia ou filial)
    if ($request->filled('province')) {
        $province = trim((string) $request->input('province'));
        $query->whereHasMorph('owner',
            [Pharmacy::class, PharmacyBranch::class],
            function ($q) use ($province) {
                $q->where('province', $province);
        });
    }

    // Apenas farmácias activas e filiais aprovadas
    $query->where(function ($q) {
        $q->whereHasMorph('owner', [Pharmacy::class], function ($ph) {
            $ph->where('is_active', true);
        })->orWhereHasMorph('owner', [PharmacyBranch::class], function ($br) {
            $br->where('is_active', true)->where('status', 'approved');
        });
    });

    $inventories = $query->select('medicine_inventories.*')
        ->paginate(20)->withQueryString();
    // ...
}
```

### A.2 — Transferência Atómica de Stock (MedicineTransfersController)

```php
$result = DB::transaction(function () use ($pharmacy, $branch, $data, $qty) {
    $matrixInv = MedicineInventory::query()
        ->lockForUpdate()
        ->where('id', (int) $data['matrix_inventory_id'])
        ->where('owner_type', 'pharmacy')
        ->where('owner_id', $pharmacy->id)
        ->firstOrFail();

    if ((int) $matrixInv->stock < $qty) {
        throw new \RuntimeException('Stock insuficiente.');
    }

    $matrixInv->stock = (int) $matrixInv->stock - $qty;
    $matrixInv->save();

    $destInv = MedicineInventory::query()
        ->lockForUpdate()
        ->where('owner_type', 'pharmacy_branch')
        ->where('owner_id', $branch->id)
        ->where('medicine_id', $matrixInv->medicine_id)
        ->first();

    if (! $destInv) {
        $destInv = MedicineInventory::query()->create([
            'medicine_id' => $matrixInv->medicine_id,
            'owner_type'  => 'pharmacy_branch',
            'owner_id'    => $branch->id,
            'price'       => (float) $matrixInv->price,
            'stock'       => 0,
            'is_available' => (bool) $matrixInv->is_available,
        ]);
    }

    $destInv->stock = (int) $destInv->stock + $qty;
    $destInv->save();

    MedicineTransfer::query()->create([/* ... */]);
    return [/* stock antes/depois */];
});
```

### A.3 — Autenticação API com Sanctum (AuthController)

```php
public function login(Request $request)
{
    $data = $request->validate([
        'email'    => ['required', 'email'],
        'password' => ['required', 'string'],
    ]);

    $user = User::query()->where('email', $data['email'])->first();

    if (! $user || ! Hash::check($data['password'], $user->password)) {
        return response()->json([
            'message' => 'Credenciais inválidas.'
        ], 401);
    }

    $token = $user->createToken('api-token')->plainTextToken;

    return response()->json([
        'token' => $token,
        'user'  => $user,
    ]);
}
```
